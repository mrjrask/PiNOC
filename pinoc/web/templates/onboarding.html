Onboarding wizard

Administrator-only. Passively discover candidate Pis on the LAN (ARP table + mDNS, no active scanning), fingerprint the ones you pick over a bounded SSH session, then review and confirm each suggested config/devices.json entry before it is written.

1. Discover

Reads the kernel's ARP table and anything the local avahi-browse daemon has already heard over mDNS. Nothing is scanned or probed at this step.

No scan run yet.

2. Fingerprint selected candidates

Attempts a bounded, read-only SSH session (default user/port below, override per candidate above if needed) against each checked candidate to detect hostname, OS, and known services, and to suggest roles/tags/monitored services.

3. Review and confirm

Edit the suggested JSON for each device if needed, then add it (or add every device shown at once) to the device store. Writes go through the same validation the rest of PiNOC uses; an invalid entry is rejected and nothing is written.
