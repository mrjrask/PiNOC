Repositories

Canonical codebases and the working trees deployed from them. Every spelling of one remote (https, scp-style, ssh, trailing .git) normalizes to a single repository, and each working tree per device is a deployment with its own observed revision, dirty state, and freshness -- so two devices on different commits appear separately, and "which devices run this repo?" never needs live SSH. Phases: observations are read-only (the Phase 2 deployment engine consumes these records); deployments age from clean to stale when their last revision observation outlives the freshness floor, and a failed collection never erases the last success.
